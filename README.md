## 🎯 Что это

Автономный Telegram-бот для продажи VPN-подписок с интеграцией панели **Remnawave**. Создан для тех, кто ценит скорость, безопасность и не терпит лишних вопросов.

**Стиль:** Строгий монохром. Киберпанк. Никаких лишних эмодзи — только функция.

**Обращение:** Дерзкое и неформальное. Без корпоративной вежливости.

## ⚡ Функционал

### Основные возможности
- 🔐 **Подписка в 30 секунд** — выбрал тариф → оплатил → получил ключ
- 📊 **Статус в реальном времени** — трафик, устройства, срок действия
- 💰 **Баланс** — пополнение через CryptoBot (USDT, TON, BTC, ETH)
- 🔄 **Автопродление** — не отключайся, мы всё сделаем сами

### Платёжные системы
| Система | Статус |
|---------|--------|
| CryptoBot (крипта) | ✅ |
| ЮMoney / QIWI | 🔜 |

- 🤝 **Реферальная программа** — приводи друзей, получай бонусы
- 🎁 **Промокоды** — разовые бонусы на баланс
